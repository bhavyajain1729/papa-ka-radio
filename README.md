# 📻 Papa Ka Radio

A nostalgic 90s Indian radio experience built using HTML, CSS and JavaScript.

## Features
- 🎵 YouTube powered music player
- 📻 Retro radio UI
- 📼 Cassette loading animation
- 📱 Fully responsive design
- ⏭ Next / Previous songs
- 🎚 Custom progress bar

## Tech Stack
HTML5
CSS3
JavaScript
YouTube IFrame API
